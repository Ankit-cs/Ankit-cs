### About Me

- **[iTantra](https://itantrav1.vercel.app)** — Offline mesh-networked voice walkie-talkie for disaster response supporting 10 Indian languages.
- **[LabelX](https://labelxv1.vercel.app)** — AI-powered data labeling and OCR frontend built with Next.js 16 and Tesseract.js.
- **[AstraSearch](https://astrasearchv1.vercel.app)** — AI-Powered Hybrid Search Engine using RAG, BM25, FAISS, and LangGraph.
- **[MyCFAnalytic](https://mycfanalytics.vercel.app)** — A comprehensive analytics dashboard for Codeforces profiles and competitive programming insights.
- **[NexusAI](https://nexusal.vercel.app)** — A production-grade AI orchestration platform with multi-agent workflows.
- **[Shrink](https://shrink-pi.vercel.app)** — A highly scalable, edge-optimized URL Shortener leveraging Cloudflare Edge Functions and KV.
- **[ProPriceTracker](https://buykarley.vercel.app)** — Advanced e-commerce price monitoring agent running serverless cron jobs.
- **[Treqo](https://treqocom.vercel.app)** — Real-time collaborative bill-splitting application with Next.js 15 and Convex.
